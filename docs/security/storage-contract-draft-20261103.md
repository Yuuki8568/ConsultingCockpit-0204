# Cockpit保存構成：契約管理票・説明文の更新案

未適用の案。締結済み契約、案件別の合意、公開中の契約テンプレートを変更するものではない。確認のない保存期間・保存国・再委託条件を補完して確定しない。

## 現在の事実として記録できる内容

Cockpitの案件・リード等の業務内容はブラウザ内で暗号化し、端末内とサーバー側のデータベースへ保存・同期する。アプリはCloudflare Workers上で稼働している。業務データのサーバー側正本は既存のlibSQL接続先であり、業務データをCloudflare D1へ移行済みではない。独立した監査照合記録にはCloudflare D1を使用している。

業務内容の暗号化と、アカウント・セッション・端末・監査等の管理情報の取扱いは異なる。管理情報まで同じ方式で端末内暗号化されるという説明はしない。

録音・動画原本は案件DBの同期とは別管理である。案件データの暗号化や同期から、原本のクラウド保存・暗号化を推定しない。フォルダーへの自動バックアップと、そのフォルダーの外部クラウド同期も別の処理として確認する。

## D1移行完了後に使用する説明案

「Cockpitの案件・リード等の業務内容は、利用端末のブラウザ内で暗号化し、暗号化された状態でCloudflare D1へ保存・同期します。表示時の復号は利用端末で行います。ログイン、端末、更新時刻、監査等の管理情報は業務内容とは区別して管理します。録音・動画原本の保管は案件DBの同期とは別に定め、案件別情報管理票に保存先・共有範囲・暗号化の有無を記録します。」

適用条件：本番切替と保存先照合が完了し、案件別契約条件と矛盾しないこと。未完了の間はこの文章を移行済みの説明として使用しない。

## 案件別情報管理票で確定させる項目

- 対象情報・利用目的・端末コピー・閲覧者・保存サービスと契約上の事業者
- 保存地域に関する顧客の制限と、サービスの実際の提供条件。地域ヒントだけで日本国内限定と記載しない
- 再委託・保存先変更について既存契約が求める通知/承諾と、その確認記録
- 業務データ、原本、証憑、監査証跡、暗号文旧世代のそれぞれの保持期間・削除期限・担当者
- バックアップ等に残る期間とアクセス保護。現状の自動完全削除停止と矛盾する即時消去保証をしない
- AI文字起こし等への外部送信はDB保存と分け、利用先・送信内容・保持条件・必要な合意を確認

これらの実際の案件条件は本調査では取得していない。現行の契約事実確認欄 `informationManagement`、`retentionDeletion`、`dpaImplementationEvidence` に確認結果を記録する。既に合意した本文を一律に差し替えず、必要な変更手続を契約ごとに判断する。
