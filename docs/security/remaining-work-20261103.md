## D1部品の利用条件

`cloudflare/d1/atomic-batch.ts` は信頼済みサーバーコードが用意したSQLだけを受け取る内部部品。認証・署名検証・利用者分離を代替しない。条件付き更新が0件でもD1はSQLエラーにしないため、直後のCHECK制約で更新件数を検査する。SQLite changes()は直前のトップレベル文の更新件数を数えるため、トリガー内の更新件数をこの部品で検証してはならない。

すべての文は一回のD1 batchに渡す。失敗時の逐次実行フォールバックはない。補助テーブルは成功時にも空へ戻す。部品とテストの追加だけで移行完了とは判断しない。
