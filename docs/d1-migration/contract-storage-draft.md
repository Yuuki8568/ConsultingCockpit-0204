# 保存基盤変更に伴う契約関連の改訂案

作成日：2026-11-01。検討用。契約雛形の採用版・締結済み本文への自動適用なし。
D1は空の移行先を作成した段階であり、移行済みとして顧客へ案内しない。

## 現行雛形の確認結果

`approved-terms.ts` の案件別情報管理票は「基本保存先はCockpit、副保存先はGoogleドライブ」「実際の構成を記録する」と定め、現行の `contract-latest.ts` に継承されている。
管理票は業務委託契約、AI特約、NDA、個人情報取扱い覚書等の情報管理を具体化する。既存雛形の再委託承諾、第三者への秘密情報開示、返還削除条件を緩めない。

## 変更対象

| 対象 | 対応 |
|---|---|
| 案件別情報管理票 | Cloudflare Workers/D1、Google Drive、端末コピーの役割・対象・アクセス者を具体化 |
| 個人情報取扱い覚書（DPA） | サービス条件、外国関連、安全管理、保持と削除を実装・契約事実に合わせて記録 |
| NDA・業務委託契約 | 個別に定めた保存先制限・再委託承諾・情報開示制限との整合を確認 |
| AI特約 | 保存基盤の変更だけを理由にAI送信・学習利用を許可する条項へ変更しない |
| プライバシーポリシー等 | 現行の公開本文を取得し、実態に合わせた説明の修正要否を判定（未確認） |
| 締結済み文書 | 本文を保存。変更合意が必要な案件は別の覚書・管理票改訂として記録 |

## 情報管理票に追加する記載案（切替完了後、案件の実態に合わせて採用）

「本案件の顧客・案件・営業情報および文字起こし本文は、乙の管理するCockpitで取り扱い、その業務データ本文を端末上で暗号化したうえでCloudflare D1に保存する。画面およびAPIの実行にはCloudflare Workersを利用する。認証情報・更新情報などの管理用情報は、業務本文と異なる形式で保存される。暗号化の対象・鍵の管理方法・閲覧可能者は本管理票に記録する。」

「副保存先として、設定済みのGoogle Drive同期対象フォルダーを利用する。案件データのバックアップは暗号化する。録音・動画原本、端末コピー、バックアップの保存対象と暗号化の有無は区別して記録する。クラウドへの同期完了と端末フォルダーへの書込み完了は区別する。」

「録音・動画原本をD1に保存する運用は含まない。R2等への原本保管を追加する場合は、保存目的、対象情報、アクセス制御、保存地域、保持・削除、必要な承諾を確認したうえで管理票を改訂する。」

「第三者による閲覧または業務の再委託を行う場合は、適用される契約・法令に従い、対象者、必要性、権限範囲、秘密保持義務および必要な事前承諾を確認する。信頼関係があることのみを理由として閲覧を許可しない。」

「返還・削除時は、通常利用データ、端末コピー、旧保存基盤、Google Driveの履歴・ごみ箱、復旧用バックアップを区分し、削除済み対象と技術的・法令上の理由で残存する対象、残存理由、保護措置、消去予定を報告する。」

## 本番切替前に確定する事実

- 対象案件にクラウド禁止、国内限定、特定事業者限定、書面承諾要件がないか。
- CloudflareおよびGoogleの実際の契約主体・利用条件・DPA・処理範囲。暗号化しているだけで第三者提供・委託に該当しないとは断定しない。
- 保存・処理地域と国外関係。D1のAPAC指定は日本限定を意味しない。国を特定できない場合の理由・参考情報を含む説明を検討する。
- 暗号化が適用される業務本文と、平文の認証・同期メタデータの範囲。
- 運営者、復号鍵保管者、端末、旧DB、Driveの共有権限。未確認者を「閲覧不可」と記載しない。
- 保存期間、Time Travelの利用プラン別保持期間、Google Drive履歴、旧DBの保持・削除時期。
- 通知だけで足りるか、変更合意・再委託承諾が必要かを既存契約ごとに判断。顧客への送信は別の明示指示がある場合のみ実施。
