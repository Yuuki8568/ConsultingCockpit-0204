# 自動バックアップ

MacのChromeでCockpitを開き、設定 → 自動バックアップ → 保存先フォルダーを選択。
Google Driveの同期フォルダー内の「Cockpit 自動バックアップ」を選ぶ。
「保存を許可して今すぐ実行」で初回の保存を確認する。

- 01_案件データ_暗号化: 金庫パスフレーズによる既存のportable format 2。案件・設定・文字起こし等のVaultState全体。日付とランダム識別子で世代保存。
- 02_録音・動画原本: 原本と8MiB単位のSHA-256検証情報。原本は暗号化されずDriveにも同期される。フォルダーは初回設定時に作成される。
- 03_復元手順・検証記録: 復元案内と各保存の原本不足件数。

開いて解錠している間に24時間ごと。終了・スリープ中の実行はできず、次回解錠で期限超過分を保存する。ブラウザーの許可が失効した場合は設定から許可し直す。スマートフォンでは設定しない。

原本は新規取り込み時にコピー。既存のブラウザー内原本もバックアップ時に回収する。以前の大容量原本や他端末の原本は自動取得できないので、設定から対象録音と元ファイルを指定する。不足があれば全体バックアップ未完了と表示する。

Google Driveへのアップロード完了はアプリから検証できない。Driveの同期完了とクラウド側のファイル存在を確認する。原本・ケースJSONとも書き出した内容を読み戻して検証する。JSONは書き出し前に復号して元スナップショットと一致することも確認する。

復元: 01のJSONを設定のバックアップ読込で選択し、保存時の金庫パスフレーズを入力。02の原本は該当案件で再取り込み（別の録音として追加）。パスフレーズは別の安全な場所に保管。古い世代は自動削除しない。Mac全体・未登録ファイル・ログイン秘密情報は対象外。

検証: `BENCH_CHROMIUM=/path/to/chrome-headless-shell node scripts/test-automatic-backup.cjs` を packages/web 内から実行。実ブラウザーのOPFSを用い、暗号化、独立復元、原本補完、破損検出、日次抑制、停止、施錠、権限拒否、排他、複数チャンク保存を検証する。
