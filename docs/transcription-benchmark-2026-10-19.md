# 日本語音声の実認識試験（2026-10-19）

追記: この報告は修正前の記録。2026-10-20の修正と再試験は [こちら](transcription-fix-2026-10-20.md)。

## 判定

現行の Whisper tiny / q8 / WASM 実装は本番反映を保留する。処理速度よりも、意味の変わる誤認識・文章の大量反復・特定区間での認識失敗が問題。以前の3時間無音試験は読み込みと再開を検証したもので、音声認識の品質や安定性を保証していない。

## 条件

- 対象: feature commit `62133c70201497de17697cb12cddae30ce27319c`。
- ブラウザー: Playwright 1.56.1 Chromium headless、Linux x86_64、AMD EPYC 9V74 の仮想環境（8 CPU相当の割当）。WASM推論は1スレッド。
- 音声: Kotoba Technologies の公開された複数話者日本語サンプル。MP3コンテナー時間26.644898秒、デコード音声26.618775510秒。
- 配布元: https://huggingface.co/kotoba-tech/kotoba-whisper-v2.2 （sample_audio/sample_diarization_japanese.mp3）。認識モデルはKotobaではなく、アプリに実装済みのWhisper tiny。
- モデルは固定版を事前取得し、ブラウザーのモデルGETにローカルファイルで応答。モデル読込・推論・デコードは計測に含むが、初回インターネットダウンロード時間は含まない。
- 同じサンプルを反復して300秒の16kHzモノラルWAVを作成。これは連続処理の負荷試験であり、内容が異なる5分の自然対話でも、1時間・3時間の会議でもない。
- アカウント・実DBは使用せず、チェックポイント保存コールバックで計測。DB保存・暗号化同期の時間は含まない。

## 実測

| 試験 | 結果 |
| --- | --- |
| 元の約26.62秒MP3 | 7.246秒で完了、167文字を出力 |
| 300秒WAV・1回目 | 60秒分を15.587秒、120秒分を29.510秒で保存。第3区間で推論エラー、完走せず |
| 同じWAV・再試験 | 60秒分を15.573秒、120秒分を29.041秒で保存。同じ第3区間で再び推論エラー |
| 失敗区間（118〜182秒の64秒）だけを切り出して新しいWorkerで処理 | 推論エラーを再現。Workerを長時間使い回したことだけでは説明できない |

最初の2分の処理速度は音声時間の約24〜25%。仮に維持できれば1時間約15分相当だが、実際にはエラーで止まるため完了時間の予測や性能保証には使えない。利用者のPCやスマホでの測定ではない。

## 精度・安定性

- 配布元ページの参照出力にある「屋外の気温」が、この実装では「お国会の基本」など意味の異なる表現になった。
- 300秒試験の最初の区間で、参照出力にない「ビデオのビデオがあるから」という文章が大量反復した。入力自体も反復素材だが、このフレーズの生成反復は別の問題。
- 単語・文意の取り違えが複数あり、議事録として無修正で利用できる品質ではない。
- 参照は別モデルの公開出力であり、人手で確定した正解文字列ではない。CER/WER・正解率は算出していない。
- 実行時診断はONNXモデル実行エラー（数値例 `41127784`、新Workerでは `88801808`）。ネットワーク取得失敗ではなく推論中に発生したが、低レベルの原因は未確定。
- 第3区間で失敗したため、長時間の境界欠落・重複がないとは評価できない。

## 次の改善・再試験

日本語向けに精度を高めたモデルまたはより大きいモデルを、端末内処理を維持して比較する。推論失敗区間を回帰試験に含め、モデルとランタイムの組み合わせを確認する。改善後に自然対話の正解付き試料で品質を測り、1時間・3時間の実音声、利用者のPC・スマホで再評価する。本試験ではモデル・ランタイムの仕様変更や本番デプロイはしていない。

## 再現

Viteを4180番で起動後、packages/webから実行:

```sh
BENCH_FIXTURE=/absolute/path/audio.wav \
BENCH_RESULT=/absolute/path/result.json \
TRANSCRIPTION_MODEL_DIR=/absolute/path/pinned-model \
node scripts/benchmark-transcription.cjs
```

結果JSONには認識文が含まれる。私的な録音を試す場合は公開リポジトリに保存しない。
